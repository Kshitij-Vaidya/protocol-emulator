# Architecture Decision Records

Write one file for each decision. Use the name format `NNNN-short-title.md`.
Each file has these sections: Context, Options, Decision (or Proposal), and
Consequences. Each file has one status: Proposed, Accepted, or Superseded by
ADR-NNNN.
